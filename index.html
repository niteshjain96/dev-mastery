HOW TO USE

Reading this book

Every topic is a Q-block

Question, then the spoken definition, then an example, then code you write, then the cross-questions. Read the definition until you can say it without looking at it. That is the 20 seconds after the interviewer stops talking.

AI off, autocomplete off, timer on

Every drill in this book is to be done by hand. Your manual coding has thinned out; that is the specific thing the machine coding round will expose. Open the solution only after the timer ends, and only deliberately.

Reading order is not run order

Read in sequence. But start the machine coding builds in week two and React alongside Part III — interviews will not wait for you to finish MongoDB.

Say the answers out loud

Silent reading produces recognition, not recall. An interview needs recall, under mild stress, with someone watching. Speak every Say this box aloud once. It feels stupid. It works.
